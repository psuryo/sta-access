Relationship dan Impor Data

Membuat relasi antar tabel, memahami integritas referensial, serta mengimpor data dari file Excel dan CSV ke dalam Access.

⏱️ 90 menit 🎯 Praktik Inti 📦 Microsoft Access

Tujuan Pembelajaran

  • Memahami konsep relationship (relasi) antar tabel dalam database.
  • Mengenal jenis-jenis relasi: One-to-Many, One-to-One, dan Many-to-Many.
  • Mampu membuat relasi antar tabel menggunakan jendela Relationships.
  • Memahami dan menerapkan Referential Integrity (integritas referensial).
  • Mampu mengimpor data dari file Excel dan CSV ke dalam tabel Access.

1. Mengapa Relationship Dibutuhkan?

Dalam praktik pertemuan sebelumnya, kita membuat tabel Anggota dan Buku secara terpisah. Namun kedua tabel tersebut saling berkaitan: satu anggota bisa meminjam banyak buku. Agar data tidak diketik berulang-ulang dan tetap konsisten, tabel-tabel tersebut perlu dihubungkan melalui sebuah relationship.

Relasi dibangun dengan menghubungkan Primary Key pada satu tabel dengan Foreign Key pada tabel lain. Foreign Key adalah field pada suatu tabel yang nilainya mengacu pada Primary Key di tabel lain.

2. Jenis-Jenis Relationship

Jenis Relasi Penjelasan Contoh
One-to-Many Satu record pada tabel pertama dapat berelasi dengan banyak record pada tabel kedua Satu Anggota dapat meminjam banyak Buku
One-to-One Satu record pada tabel pertama hanya berelasi dengan satu record pada tabel kedua Satu Karyawan memiliki satu Kartu Identitas
Many-to-Many Banyak record pada tabel pertama berelasi dengan banyak record pada tabel kedua (memerlukan tabel penghubung) Banyak Siswa mengikuti banyak Mata Pelajaran
Perlu diketahui: Relasi One-to-Many adalah jenis relasi yang paling sering digunakan dalam desain database sehari-hari.

3. Membuat Relationship di Access

  1. Pastikan tabel Anggota dan Buku sudah memiliki Primary Key masing-masing.
  2. Tambahkan field IDAnggota pada tabel Buku sebagai Foreign Key untuk mencatat siapa yang meminjam.
  3. Buka tab Database Tools, lalu klik tombol Relationships.
  4. Pada jendela Show Table, pilih kedua tabel yang akan direlasikan, klik Add, lalu Close.
  5. Klik dan seret (drag) field IDAnggota dari tabel Anggota ke field IDAnggota pada tabel Buku.
  6. Pada kotak dialog Edit Relationships yang muncul, aktifkan opsi Enforce Referential Integrity.
  7. Klik Create untuk membentuk relasi. Garis penghubung akan muncul di antara kedua tabel.

4. Referential Integrity (Integritas Referensial)

Referential Integrity adalah aturan yang menjaga agar data pada Foreign Key selalu konsisten dengan data pada Primary Key tabel induknya. Dengan aturan ini, Access akan mencegah:

  • Penginputan nilai Foreign Key yang tidak ada pada tabel induk (misalnya IDAnggota yang belum terdaftar).
  • Penghapusan record induk yang masih memiliki data terkait pada tabel anak, kecuali fitur Cascade Delete diaktifkan.
  • Perubahan nilai Primary Key induk tanpa memperbarui Foreign Key terkait, kecuali fitur Cascade Update diaktifkan.
Perhatian: Jika muncul pesan error saat mengaktifkan Referential Integrity, biasanya disebabkan tipe data kedua field yang direlasikan tidak sama, atau sudah ada data pada tabel anak yang tidak sesuai dengan tabel induk.

5. Impor Data dari Excel dan CSV

Access memungkinkan data yang sudah ada di file Excel atau CSV diimpor langsung ke dalam tabel, tanpa perlu mengetik ulang satu per satu.

Impor dari Excel (.xlsx)

  1. Buka tab External Data, lalu klik New Data Source → From File → Excel.
  2. Klik Browse untuk memilih file Excel yang akan diimpor.
  3. Pilih opsi Import the source data into a new table in the current database, lalu klik OK.
  4. Pilih worksheet yang berisi data, lalu klik Next.
  5. Centang First Row Contains Column Headings jika baris pertama berisi nama kolom.
  6. Sesuaikan tipe data tiap kolom jika diperlukan, lalu klik Next hingga selesai.
  7. Tentukan Primary Key (atau biarkan Access menambahkannya otomatis), lalu klik Finish.

Impor dari CSV

  1. Buka tab External Data, lalu klik New Data Source → From File → Text File.
  2. Pilih file CSV yang akan diimpor dan ikuti wizard yang serupa dengan impor Excel.
  3. Pastikan pemisah kolom (delimiter) yang terdeteksi sudah sesuai, misalnya koma atau titik koma.
Tips: Sebelum mengimpor, pastikan format data pada Excel/CSV sudah rapi — tanpa baris kosong, gabungan sel (merge cell), atau format tanggal yang tidak konsisten — agar proses impor berjalan lancar tanpa error.

6. Langkah Praktik

  1. Buka kembali database PerpustakaanKu.accdb dari pertemuan sebelumnya.
  2. Tambahkan field IDAnggota (Number) pada tabel Buku sebagai Foreign Key.
  3. Buat relasi One-to-Many antara tabel Anggota dan Buku melalui jendela Relationships, dengan Referential Integrity aktif.
  4. Siapkan file Excel berisi minimal 5 data buku tambahan, lalu impor ke dalam tabel Buku.
  5. Periksa hasil relasi dengan membuka tabel Anggota dan melihat tanda (+) di sebelah kiri setiap record.

Ringkasan

  • Relationship menghubungkan Primary Key suatu tabel dengan Foreign Key pada tabel lain.
  • Tiga jenis relasi utama adalah One-to-Many, One-to-One, dan Many-to-Many.
  • Referential Integrity menjaga konsistensi data antar tabel yang berelasi.
  • Data dari Excel maupun CSV dapat diimpor langsung ke dalam tabel Access melalui menu External Data.
  • Format data sumber sebaiknya dirapikan terlebih dahulu sebelum proses impor dilakukan.

Latihan Mandiri

  1. Jelaskan perbedaan antara relasi One-to-Many dan Many-to-Many beserta contohnya masing-masing.
  2. Apa yang terjadi jika kita mencoba menghapus record induk yang masih memiliki data anak, sementara Referential Integrity aktif tanpa Cascade Delete?
  3. Buat relasi antara tabel Peminjaman (dari latihan pertemuan 2) dengan tabel Anggota dan Buku, lalu jelaskan foreign key apa saja yang dibutuhkan.
