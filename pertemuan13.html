🟣 Pertemuan 13 · Integrasi Access & Neon.Tech

Advanced Report dalam Access

Menyempurnakan laporan Access dengan menyisipkan subreport, membuat calculated control untuk ringkasan data, menerapkan conditional formatting agar informasi penting lebih menonjol, serta mengekspor laporan akhir ke format PDF.

📚 Kelompok: Integrasi & Aplikasi Access
🎯 Sub-CPMK: CPMK1
🧭 Indikator: IK 1.2, IK 1.3
⏱️ Durasi: 100 menit
1 Tujuan Pembelajaran
  • Mahasiswa mampu menyisipkan subreport ke dalam report utama untuk menampilkan data terkait secara bersarang.
  • Mahasiswa mampu membuat calculated control menggunakan expression untuk menampilkan ringkasan atau hasil perhitungan pada report.
  • Mahasiswa mampu menerapkan conditional formatting agar data penting tampil lebih menonjol secara visual.
  • Mahasiswa mampu mengekspor report ke format PDF sebagai dokumen laporan administrasi perkantoran yang siap dibagikan.
2 Konsep Dasar Fitur Report Lanjutan

Setelah mampu membuat report dasar pada Pertemuan 12, mahasiswa akan mempelajari beberapa fitur lanjutan yang membuat laporan lebih informatif dan profesional — mulai dari menampilkan data bersarang (subreport), menghitung ringkasan otomatis (calculated control), hingga memberi penekanan visual pada data tertentu (conditional formatting).

🧾 Subreport

Report kecil yang disisipkan ke dalam report utama, mirip SubForm, untuk menampilkan data terkait secara bersarang.

🧮 Calculated Control

Text box yang nilainya berasal dari expression/rumus, bukan langsung dari field tabel, misalnya total atau rata-rata.

🎨 Conditional Formatting

Aturan tampilan otomatis yang mengubah warna/format suatu kontrol berdasarkan kondisi nilai datanya.

📄 Export to PDF

Fitur Access untuk menyimpan hasil report sebagai berkas PDF yang tata letaknya tetap terjaga saat dibagikan.

3 Praktik: Menyisipkan Subreport
1

Siapkan report utama

Buka report rpt_divisi (berdasarkan tabel divisi) dalam Design View sebagai report induk.

2

Sisipkan kontrol Subform/Subreport

Pastikan Use Control Wizards aktif, lalu pilih ikon SubForm/SubReport pada ribbon Design dan klik-tarik pada bagian Detail report utama.

3

Pilih sumber data subreport

Pilih Use existing Tables and Queries, lalu pilih tabel pegawai beserta field yang relevan (nama, jabatan, gaji).

4

Tentukan field penghubung & nama subreport

Sama seperti SubForm pada Pertemuan 11, hubungkan divisi.id dengan pegawai.divisi_id, lalu beri nama subrpt_pegawai dan klik Finish.

Group Header — DivisiDivisi: Kesekretariatan
📎 Subreport: subrpt_pegawai
Budi SantosoSekretaris5.700.000
💡 Gunakan subreport ketika data anak berasal dari tabel/query yang berbeda dari report utama, atau ketika tata letaknya perlu dirancang secara terpisah.
4 Praktik: Membuat Calculated Control
1

Tambahkan text box baru

Pada Group Footer atau Report Footer, tambahkan kontrol Text Box baru dari ribbon Design → Controls.

2

Isi expression pada Control Source

Buka Property Sheet text box, lalu isi properti Control Source dengan expression untuk menghitung total gaji per divisi:

=Sum([gaji])
3

Menghitung jumlah pegawai per divisi

=Count([nama])
4

Menghitung rata-rata gaji

=Avg([gaji])
5

Menggabungkan teks & angka

Expression juga dapat menggabungkan teks statis dengan hasil perhitungan menggunakan operator &:

="Total Pegawai: " & Count([nama]) & " orang"
Group Footer — Calculated ControlTotal Pegawai: 2 orang  ·  Total Gaji: 10.450.000  ·  Rata-rata: 5.225.000
5 Praktik: Menerapkan Conditional Formatting
1

Pilih kontrol yang akan diberi format

Klik text box gaji pada bagian Detail report, lalu buka ribbon Format → Conditional Formatting.

2

Buat aturan untuk nilai tinggi

Klik New Rule, atur kondisi Field Value Is → greater than → 5000000, lalu pilih warna latar hijau untuk menandai gaji di atas rata-rata.

3

Buat aturan untuk nilai rendah

Tambahkan aturan kedua: Field Value Is → less than → 4200000, lalu pilih warna latar merah muda untuk menandai gaji yang perlu ditinjau.

4

Periksa hasil pada Print Preview

Buka Print Preview untuk memastikan warna kondisional tampil sesuai dengan nilai gaji masing-masing pegawai.

Rina Kartika — Kepala Divisi6.200.000
Andi Wijaya — Staf Administrasi4.750.000
Hasan Ali — Staf Umum4.100.000
⚠️ Conditional formatting hanya mengubah tampilan, bukan nilai data aslinya. Pastikan ambang batas (threshold) yang digunakan telah disepakati dan relevan dengan kebutuhan laporan.
6 Praktik: Mengekspor Report ke PDF
1

Buka report pada Print Preview

Klik kanan report yang telah disempurnakan, lalu pilih Print Preview untuk memastikan tampilan akhir sudah sesuai.

2

Ekspor ke PDF

Pada ribbon Print Preview → Data → PDF or XPS, tentukan lokasi penyimpanan, lalu klik Publish.

3

Periksa hasil PDF

Buka berkas PDF yang dihasilkan untuk memastikan subreport, calculated control, dan conditional formatting tampil dengan benar seperti pada Print Preview.

ℹ️ Berkas PDF hasil ekspor bersifat statis (tidak berubah otomatis mengikuti data terbaru), sehingga perlu diekspor ulang setiap kali data sumbernya diperbarui.
7 Latihan / Tugas Praktik

📝 Tugas Individu

  1. Sisipkan subreport pegawai ke dalam report divisi yang telah dibuat pada Pertemuan 12.
  2. Tambahkan calculated control untuk menampilkan total gaji, jumlah pegawai, dan rata-rata gaji per divisi.
  3. Terapkan conditional formatting pada kolom gaji dengan minimal dua aturan (nilai tinggi dan nilai rendah).
  4. Ekspor report akhir ke PDF, lalu periksa apakah seluruh elemen (subreport, calculated control, conditional formatting) tampil dengan benar.
  5. Kumpulkan berkas PDF beserta tangkapan layar Design View sesuai format yang ditentukan dosen.
