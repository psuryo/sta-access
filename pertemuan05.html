Query Grouping, Formula, dan Parameter

Menggunakan fungsi agregat (SUM, COUNT, AVG), mengelompokkan data dengan GROUP BY, membuat calculated field, dan membangun parameter query.

⏱️ 90 menit 🎯 Praktik Inti 📦 Microsoft Access

Tujuan Pembelajaran

  • Memahami dan menggunakan fungsi agregat (SUM, COUNT, AVG, MIN, MAX) dalam query.
  • Mampu mengelompokkan data menggunakan baris Total (GROUP BY).
  • Mampu membuat calculated field untuk menghasilkan kolom hasil perhitungan baru.
  • Mampu membangun parameter query yang meminta input dari pengguna saat query dijalankan.

1. Fungsi Agregat dalam Query

Fungsi agregat digunakan untuk melakukan perhitungan ringkas terhadap sekumpulan data, misalnya menjumlahkan, menghitung jumlah record, atau mencari rata-rata. Fungsi ini diaktifkan melalui baris Total pada Query Design View (klik tombol Totals (Σ) di Ribbon tab Design).

Fungsi Kegunaan
Sum Menjumlahkan seluruh nilai numerik pada suatu field
Count Menghitung jumlah record
Avg Menghitung nilai rata-rata
Min Mencari nilai terkecil
Max Mencari nilai terbesar
Group By Mengelompokkan data berdasarkan nilai field tertentu sebelum dihitung

2. Mengelompokkan Data dengan Group By

Group By digunakan untuk mengelompokkan data berdasarkan nilai yang sama pada satu atau lebih field, sebelum fungsi agregat diterapkan pada field lain.

  1. Buat query baru dari tabel Buku melalui Query Design View.
  2. Masukkan field Pengarang dan Stok ke dalam grid.
  3. Klik tombol Totals pada Ribbon sehingga muncul baris Total pada grid.
  4. Pada kolom Pengarang, biarkan nilai baris Total tetap Group By.
  5. Pada kolom Stok, ubah nilai baris Total menjadi Sum untuk menjumlahkan stok per pengarang.
  6. Jalankan query untuk melihat total stok buku dikelompokkan per pengarang.
SELECT Pengarang, Sum(Stok) AS TotalStok FROM Buku GROUP BY Pengarang;
Perlu diketahui: Setiap field yang tidak diberi fungsi agregat harus tetap berstatus Group By, karena field tersebut menjadi dasar pengelompokan data.

3. Calculated Field

Calculated field adalah kolom baru pada query yang nilainya dihasilkan dari rumus atau perhitungan terhadap field lain, tanpa perlu disimpan sebagai field baru di tabel.

  1. Pada Query Design View, klik kolom kosong pada grid.
  2. Ketikkan rumus dengan format NamaKolomBaru: Ekspresi.
  3. Jalankan query untuk melihat hasil perhitungan pada kolom baru tersebut.
TotalHarga: [HargaSatuan] * [Jumlah]

Contoh di atas akan membuat kolom baru bernama TotalHarga yang nilainya merupakan hasil perkalian antara field HargaSatuan dan Jumlah.

Tips: Nama field yang mengandung spasi harus diapit tanda kurung siku, misalnya [Nama Lengkap], agar tidak dianggap dua kata terpisah oleh Access.

4. Parameter Query

Parameter query adalah query yang menampilkan kotak dialog untuk meminta input dari pengguna setiap kali dijalankan, sehingga kriteria filter tidak perlu ditulis tetap (statis) pada query.

  1. Buat query baru dan masukkan field yang dibutuhkan, misalnya Pengarang pada tabel Buku.
  2. Pada baris Criteria di kolom Pengarang, ketikkan teks dalam tanda kurung siku, misalnya [Masukkan Nama Pengarang:].
  3. Jalankan query. Access akan menampilkan kotak dialog yang meminta pengguna mengetikkan nama pengarang.
  4. Hasil query akan menyesuaikan dengan nilai yang diinput oleh pengguna.
SELECT JudulBuku, Pengarang, Stok FROM Buku WHERE Pengarang = [Masukkan Nama Pengarang:];
Perhatian: Teks di dalam tanda kurung siku pada parameter query tidak boleh sama persis dengan nama field yang ada di tabel, karena Access akan menganggapnya sebagai referensi field, bukan sebagai parameter.

5. Langkah Praktik

  1. Buka kembali database PerpustakaanKu.accdb.
  2. Buat query qryTotalStokPerPengarang yang menampilkan total Stok buku dikelompokkan per Pengarang menggunakan Group By dan Sum.
  3. Buat query qryJumlahAnggota yang menghitung jumlah total anggota menggunakan fungsi Count.
  4. Buat calculated field pada query buku, misalnya StatusStok: IIf([Stok]>0,"Tersedia","Habis").
  5. Buat parameter query qryCariBuku yang meminta pengguna memasukkan judul buku yang dicari.

Ringkasan

  • Fungsi agregat seperti Sum, Count, dan Avg digunakan untuk meringkas data numerik dalam query.
  • Group By mengelompokkan data berdasarkan nilai field tertentu sebelum fungsi agregat diterapkan.
  • Calculated field menghasilkan kolom baru dari rumus terhadap field lain tanpa mengubah tabel sumber.
  • Parameter query menampilkan kotak dialog input, membuat query lebih fleksibel digunakan berulang kali.

Latihan Mandiri

  1. Jelaskan perbedaan fungsi Count dan Sum beserta contoh penggunaannya.
  2. Buat calculated field untuk menghitung selisih hari antara TanggalPinjam dan TanggalKembali pada tabel Peminjaman.
  3. Buat parameter query yang menampilkan daftar anggota berdasarkan input rentang TanggalDaftar dari pengguna.
