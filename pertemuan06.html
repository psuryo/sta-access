Pengenalan Remote Database (Neon.Tech)

Memahami konsep cloud database, membuat akun Neon.Tech, serta membuat project dan database PostgreSQL pertama secara online.

⏱️ 90 menit 🎯 Praktik Inti ☁️ Neon.Tech

Tujuan Pembelajaran

  • Memahami konsep cloud database dan perbedaannya dengan database lokal seperti Access.
  • Mengenal PostgreSQL sebagai sistem manajemen basis data relasional.
  • Mampu membuat akun dan project baru di layanan Neon.Tech.
  • Mampu membuat database PostgreSQL pertama melalui Neon Console.
  • Mengenal antarmuka SQL Editor pada Neon Console.

1. Dari Database Lokal ke Cloud Database

Pada pertemuan-pertemuan sebelumnya, kita bekerja dengan Microsoft Access — sebuah database lokal yang tersimpan sebagai file .accdb di komputer. Database lokal memiliki keterbatasan: hanya bisa diakses dari komputer tempat file tersimpan, dan sulit digunakan bersama-sama secara langsung oleh banyak pengguna dari lokasi berbeda.

Cloud database (remote database) adalah database yang disimpan dan dikelola di server milik penyedia layanan, sehingga dapat diakses dari mana saja selama terhubung internet, dan mendukung banyak pengguna maupun aplikasi mengakses data yang sama secara bersamaan.

Aspek Database Lokal (Access) Cloud Database (Neon.Tech)
Lokasi penyimpanan File di komputer/laptop pengguna Server milik penyedia cloud
Akses Hanya dari komputer tempat file berada Dari mana saja via internet
Multi-user Terbatas dan rawan konflik data Didesain untuk banyak pengguna sekaligus
Bahasa database Access SQL (mirip standar SQL) PostgreSQL (standar SQL industri)

2. Mengenal PostgreSQL

PostgreSQL adalah sistem manajemen basis data relasional (RDBMS) open-source yang banyak digunakan oleh aplikasi web dan mobile skala kecil hingga besar. Konsep tabel, Primary Key, relasi, dan query yang sudah dipelajari di Access berlaku juga pada PostgreSQL — bedanya, PostgreSQL diakses menggunakan bahasa SQL standar secara langsung, bukan melalui antarmuka grafis seperti Design View di Access.

Perlu diketahui: Neon.Tech adalah salah satu penyedia layanan PostgreSQL as a Service yang menyediakan database cloud siap pakai, termasuk paket gratis (free tier) yang cukup untuk keperluan belajar dan proyek kecil.

3. Membuat Akun Neon.Tech

  1. Buka browser dan kunjungi situs resmi neon.tech.
  2. Klik tombol Sign Up, lalu daftar menggunakan akun Google, GitHub, atau email.
  3. Verifikasi akun sesuai instruksi yang dikirimkan (jika diminta).
  4. Setelah berhasil masuk, pengguna akan diarahkan ke Neon Console, yaitu dashboard utama untuk mengelola project dan database.

4. Membuat Project dan Database

Di Neon.Tech, setiap project secara otomatis menyertakan satu database PostgreSQL pertama. Satu akun dapat memiliki beberapa project sekaligus.

  1. Pada Neon Console, klik tombol Create a project (atau New Project).
  2. Beri nama project, misalnya praktikum-database.
  3. Pilih Postgres version (gunakan versi default/terbaru jika tidak yakin) dan Region server terdekat.
  4. Klik Create Project untuk membuat project beserta database default-nya.
  5. Setelah selesai, Neon akan menampilkan halaman Connection Details berisi informasi koneksi database (host, nama database, username, password).
Perhatian: Informasi connection string dan password database bersifat rahasia. Jangan membagikannya secara publik, misalnya di repository GitHub yang bersifat publik.

5. Mengenal SQL Editor pada Neon Console

Neon Console menyediakan SQL Editor berbasis web yang memungkinkan pengguna menjalankan perintah SQL langsung dari browser, tanpa perlu menginstal aplikasi tambahan.

  1. Pada Neon Console, buka menu SQL Editor di sidebar kiri.
  2. Ketikkan perintah SQL sederhana pada area editor, misalnya untuk menampilkan versi PostgreSQL yang digunakan.
  3. Klik tombol Run untuk menjalankan perintah.
  4. Hasil query akan ditampilkan pada panel di bagian bawah editor.
SELECT version();
Tips: SQL Editor pada Neon Console sangat berguna untuk uji coba perintah SQL secara cepat sebelum diterapkan pada aplikasi, tanpa perlu membuka aplikasi database client tambahan.

6. Langkah Praktik

  1. Buat akun baru di neon.tech menggunakan email atau akun GitHub/Google.
  2. Buat project baru dengan nama praktikum-[nama_mahasiswa].
  3. Catat informasi Connection Details (host, database, username) pada project tersebut.
  4. Buka SQL Editor dan jalankan perintah SELECT version();, lalu amati hasilnya.
  5. Ambil tangkapan layar (screenshot) hasil project dan SQL Editor sebagai bukti praktik.

Ringkasan

  • Cloud database memungkinkan data diakses dari mana saja dan digunakan bersama oleh banyak pengguna.
  • Neon.Tech adalah layanan PostgreSQL as a Service dengan paket gratis untuk belajar dan proyek kecil.
  • Setiap project di Neon.Tech secara otomatis menyertakan satu database PostgreSQL.
  • Connection Details berisi informasi rahasia yang digunakan untuk menghubungkan aplikasi ke database.
  • SQL Editor pada Neon Console memungkinkan perintah SQL dijalankan langsung dari browser.

Latihan Mandiri

  1. Jelaskan dua keuntungan utama menggunakan cloud database dibandingkan database lokal seperti Access.
  2. Mengapa connection string dan password database tidak boleh dibagikan secara publik?
  3. Buat sebuah project baru di Neon.Tech dan jalankan perintah SELECT current_database(); pada SQL Editor, lalu jelaskan hasil yang muncul.
