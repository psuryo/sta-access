Membuat Database dan Tabel

Membuat file database baru, mendesain struktur tabel, memahami tipe data, menetapkan primary key, dan input data ke dalam tabel.

⏱️ 90 menit 🎯 Praktik Inti 📦 Microsoft Access

Tujuan Pembelajaran

  • Mampu membuat file database baru menggunakan Microsoft Access.
  • Memahami cara mendesain struktur tabel melalui Design View.
  • Mengenal berbagai tipe data field beserta kegunaannya masing-masing.
  • Mampu menetapkan Primary Key pada sebuah tabel.
  • Mampu melakukan input, edit, dan hapus data melalui Datasheet View.

1. Membuat Database Baru

Setiap pekerjaan di Microsoft Access dimulai dari sebuah file database (berekstensi .accdb). Satu file database dapat menampung banyak tabel, query, form, dan report sekaligus, sehingga sebaiknya satu file digunakan untuk satu topik/aplikasi.

  1. Buka Microsoft Access, lalu pilih Blank Database pada Backstage View.
  2. Beri nama file, misalnya PerpustakaanKu.accdb, lalu tentukan lokasi penyimpanan folder.
  3. Klik tombol Create untuk membuat file database baru.
  4. Access akan otomatis membuka Table1 dalam mode Datasheet View, siap untuk didesain.
Perlu diketahui: Nama file database sebaiknya singkat, deskriptif, dan tanpa spasi atau karakter khusus, misalnya DataSiswa.accdb alih-alih Data Siswa Kelas 1 (final).accdb.

2. Mendesain Struktur Tabel

Tabel dapat didesain melalui dua tampilan: Datasheet View (langsung mengetik nama field) atau Design View (menentukan nama field, tipe data, dan properti secara rinci). Design View lebih disarankan untuk struktur tabel yang lebih kompleks.

  1. Klik kanan pada Table1 di Navigation Pane, pilih Design View.
  2. Beri nama tabel, misalnya Anggota, lalu klik OK.
  3. Pada kolom Field Name, ketikkan nama field satu per satu, misalnya: IDAnggota, Nama, Alamat, TanggalDaftar.
  4. Pada kolom Data Type, pilih tipe data yang sesuai untuk setiap field.
  5. Isi Description (opsional) untuk menjelaskan fungsi field tersebut.
  6. Atur properti tambahan pada panel Field Properties di bagian bawah, misalnya Field Size atau Format.

3. Tipe Data (Data Type) dalam Access

Pemilihan tipe data yang tepat memengaruhi ukuran penyimpanan, validasi input, dan kemampuan pengolahan data selanjutnya.

Tipe Data Kegunaan
Short Text Teks pendek maksimal 255 karakter, misalnya Nama atau Alamat
Long Text Teks panjang seperti deskripsi atau catatan
Number Data angka untuk keperluan perhitungan, misalnya Jumlah Barang
Date/Time Data tanggal dan/atau waktu, misalnya Tanggal Lahir
Currency Data nilai uang dengan format mata uang otomatis
AutoNumber Angka otomatis bertambah (increment), umum dipakai untuk Primary Key
Yes/No Data logika/boolean, misalnya status Lunas atau Belum Lunas
Lookup Wizard Menampilkan daftar pilihan nilai yang diambil dari tabel lain atau daftar tetap
Tips: Gunakan tipe data AutoNumber untuk field ID agar setiap record memiliki identitas unik secara otomatis tanpa perlu diinput manual.

4. Menetapkan Primary Key

Primary Key adalah field yang nilainya unik untuk setiap record dan tidak boleh kosong (null). Primary Key berfungsi sebagai identitas record dan menjadi dasar relasi antar tabel.

  1. Pada Design View, klik pada baris field yang akan dijadikan Primary Key, misalnya IDAnggota.
  2. Klik tombol Primary Key pada Ribbon tab Design, atau klik kanan field lalu pilih Primary Key.
  3. Ikon kunci 🔑 akan muncul di sebelah kiri nama field yang menandakan field tersebut adalah Primary Key.
Perhatian: Setiap tabel sebaiknya hanya memiliki satu Primary Key. Field yang dijadikan Primary Key tidak boleh memiliki nilai duplikat maupun kosong.

5. Input Data melalui Datasheet View

Setelah struktur tabel selesai didesain, data dapat dimasukkan melalui Datasheet View yang tampilannya menyerupai lembar kerja spreadsheet.

  1. Simpan tabel, lalu klik tombol View di pojok kiri atas dan pilih Datasheet View.
  2. Ketikkan data pada setiap baris sesuai dengan field yang telah dibuat.
  3. Gunakan tombol Tab untuk berpindah antar kolom dan Enter untuk baris baru.
  4. Untuk mengedit data, klik langsung pada sel yang ingin diubah.
  5. Untuk menghapus record, klik kanan pada selector baris lalu pilih Delete Record.
Perlu diketahui: Access otomatis menyimpan setiap perubahan data saat berpindah baris, sehingga tidak diperlukan perintah "Save" khusus untuk data yang diinput.

6. Langkah Praktik

  1. Buat database baru bernama PerpustakaanKu.accdb.
  2. Buat tabel Anggota dengan field: IDAnggota (AutoNumber, Primary Key), Nama (Short Text), Alamat (Short Text), TanggalDaftar (Date/Time).
  3. Buat tabel Buku dengan field: IDBuku (AutoNumber, Primary Key), JudulBuku (Short Text), Pengarang (Short Text), Stok (Number).
  4. Masukkan minimal 5 data pada masing-masing tabel melalui Datasheet View.
  5. Simpan database.
Tips: Rencanakan terlebih dahulu daftar field dan tipe datanya di atas kertas sebelum mulai mendesain tabel di Access agar struktur database lebih rapi dan terarah.

Ringkasan

  • Database baru dibuat melalui Blank Database pada Backstage View dan disimpan dalam format .accdb.
  • Struktur tabel didesain melalui Design View dengan menentukan Field Name dan Data Type.
  • Setiap field memiliki tipe data yang berbeda sesuai jenis data yang akan disimpan.
  • Primary Key menjamin setiap record memiliki identitas unik dan menjadi dasar relasi antar tabel.
  • Input data dilakukan melalui Datasheet View dan tersimpan otomatis setiap berpindah baris.

Latihan Mandiri

  1. Jelaskan perbedaan antara tipe data Short Text dan Long Text.
  2. Mengapa field Primary Key tidak boleh memiliki nilai yang kosong atau duplikat?
  3. Buat tabel baru bernama Peminjaman dengan field: IDPeminjaman (AutoNumber, Primary Key), TanggalPinjam (Date/Time), TanggalKembali (Date/Time), Status (Yes/No).
