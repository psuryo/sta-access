Query Remote Database — JOIN & Subquery

Memperdalam kemampuan mengambil dan menganalisis data dengan berbagai variasi SELECT, WHERE, dan wildcard LIKE, dilanjutkan dengan menggabungkan data antar tabel menggunakan JOIN, subquery, dan view pada PostgreSQL di Neon.Tech.

📚 Kelompok: Remote Database — Neon.Tech
🎯 Sub-CPMK: CPMK2
🧭 Indikator: IK 1.3, IK 3.1
⏱️ Durasi: 100 menit
1 Tujuan Pembelajaran
  • Mahasiswa mampu menyusun berbagai variasi query SELECT untuk menampilkan dan mengurutkan data.
  • Mahasiswa mampu menyaring data menggunakan klausa WHERE dengan berbagai operator perbandingan dan logika.
  • Mahasiswa mampu mencari data berdasarkan pola teks menggunakan wildcard LIKE / ILIKE.
  • Mahasiswa mampu menggabungkan data antar tabel menggunakan INNER JOIN dan LEFT JOIN, serta menyusun subquery dan view sebagai alat analisis data untuk pengambilan keputusan.
2 Dataset yang Digunakan

Seluruh contoh pada pertemuan ini menggunakan tabel pegawai dan divisi yang datanya sudah tersedia dari praktik Pertemuan 7. Berikut contoh isi kedua tabel sebagai acuan saat mencoba query di SQL Editor Neon.Tech.

3 Praktik: Variasi SELECT & Pengurutan Data
1

Menampilkan seluruh kolom

SELECT * FROM pegawai;
2

Menampilkan kolom tertentu

SELECT nama, jabatan, gaji FROM pegawai;
3

Mengurutkan data — ORDER BY

SELECT nama, gaji FROM pegawai ORDER BY gaji DESC;
4

Membatasi jumlah baris — LIMIT

SELECT nama, jabatan FROM pegawai ORDER BY nama ASC LIMIT 3;
5

Menampilkan nilai unik — DISTINCT

SELECT DISTINCT jabatan FROM pegawai;
4 Praktik: Menyaring Data dengan WHERE
1

Perbandingan sederhana

SELECT * FROM pegawai WHERE jabatan = 'Staf Administrasi';
2

Operator lebih besar / lebih kecil

SELECT nama, gaji FROM pegawai WHERE gaji >= 4750000;
3

Rentang nilai — BETWEEN

SELECT nama, gaji FROM pegawai WHERE gaji BETWEEN 4200000 AND 5800000;
4

Menggabungkan syarat — AND / OR

SELECT nama, jabatan, gaji FROM pegawai WHERE jabatan = 'Staf Administrasi' AND gaji > 4600000; SELECT nama, jabatan FROM pegawai WHERE jabatan = 'Sekretaris' OR jabatan = 'Kepala Divisi';
5

Beberapa pilihan sekaligus — IN

SELECT nama, divisi_id FROM pegawai WHERE divisi_id IN (1, 3);
6

Data yang belum terisi — IS NULL

SELECT nama FROM pegawai WHERE divisi_id IS NULL;
5 Praktik: Pencarian Pola Teks dengan Wildcard (LIKE)

Wildcard digunakan bersama LIKE untuk mencari data berdasarkan pola teks. Tanda % mewakili sejumlah karakter apa pun, sedangkan _ mewakili tepat satu karakter.

1

Diawali huruf tertentu

SELECT nama FROM pegawai WHERE nama LIKE 'B%';

Menampilkan nama yang diawali huruf "B", misalnya "Budi Santoso".

2

Diakhiri huruf tertentu

SELECT nama FROM pegawai WHERE nama LIKE '%i';

Menampilkan nama yang diakhiri huruf "i", misalnya "Rina Kartika".

3

Mengandung kata tertentu

SELECT nama FROM pegawai WHERE nama LIKE '%san%';

Menampilkan nama yang mengandung kata "san", misalnya "Hasan Ali".

4

Wildcard satu karakter — garis bawah ( _ )

SELECT nama FROM pegawai WHERE nama LIKE '_udi Santoso';

Tanda "_" mewakili tepat satu karakter di posisi tersebut, cocok dengan "Budi Santoso".

5

Pencarian tanpa membedakan huruf besar/kecil — ILIKE

SELECT nama FROM pegawai WHERE nama ILIKE '%siti%';

Tetap menemukan "Siti Aminah" walau pola ditulis huruf kecil semua.

6

Kombinasi wildcard dengan kondisi lain

SELECT nama, jabatan FROM pegawai WHERE nama LIKE '%a%' AND jabatan = 'Staf Administrasi';
6 Praktik: Menggabungkan Tabel dengan JOIN
1

INNER JOIN dasar

Menampilkan pegawai beserta nama divisinya — hanya pegawai yang sudah memiliki divisi.

SELECT pegawai.nama, pegawai.jabatan, divisi.nama_divisi FROM pegawai INNER JOIN divisi ON pegawai.divisi_id = divisi.id;
2

Menggunakan alias tabel — AS

Alias mempersingkat penulisan query, terutama saat melibatkan banyak tabel.

SELECT p.nama, p.jabatan, d.nama_divisi FROM pegawai AS p INNER JOIN divisi AS d ON p.divisi_id = d.id;
3

LEFT JOIN — menampilkan seluruh data pegawai

Pegawai yang belum memiliki divisi tetap tampil, dengan nilai nama_divisi kosong (NULL).

SELECT p.nama, d.nama_divisi FROM pegawai AS p LEFT JOIN divisi AS d ON p.divisi_id = d.id;
4

JOIN dikombinasikan dengan WHERE

Menampilkan pegawai pada divisi tertentu saja.

SELECT p.nama, p.jabatan, d.nama_divisi FROM pegawai AS p INNER JOIN divisi AS d ON p.divisi_id = d.id WHERE d.nama_divisi = 'Keuangan';
5

JOIN dikombinasikan dengan wildcard LIKE

SELECT p.nama, d.nama_divisi FROM pegawai AS p INNER JOIN divisi AS d ON p.divisi_id = d.id WHERE p.nama LIKE '%a%';
6

JOIN dengan pengurutan hasil

SELECT p.nama, d.nama_divisi, p.gaji FROM pegawai AS p LEFT JOIN divisi AS d ON p.divisi_id = d.id ORDER BY p.gaji DESC;
💡 Gunakan INNER JOIN saat hanya ingin data yang lengkap/berpasangan, dan LEFT JOIN saat ingin tetap menampilkan seluruh data dari tabel utama walau sebagian relasinya belum terisi.
7 Praktik: Subquery & View
1

Subquery pada klausa WHERE

Menampilkan pegawai dengan gaji di atas rata-rata seluruh pegawai.

SELECT nama, gaji FROM pegawai WHERE gaji > (SELECT AVG(gaji) FROM pegawai);
2

Subquery pada klausa FROM

Menghitung jumlah pegawai per divisi menggunakan subquery sebagai tabel sementara.

SELECT nama_divisi, jumlah_pegawai FROM ( SELECT d.nama_divisi, COUNT(p.id) AS jumlah_pegawai FROM divisi AS d LEFT JOIN pegawai AS p ON p.divisi_id = d.id GROUP BY d.nama_divisi ) AS rekap_divisi;
3

Membuat VIEW dari hasil JOIN

Menyimpan query gabungan pegawai & divisi sebagai view agar dapat dipanggil kembali tanpa menulis ulang query.

CREATE VIEW data_pegawai_lengkap AS SELECT p.nama, p.jabatan, d.nama_divisi, p.gaji FROM pegawai AS p LEFT JOIN divisi AS d ON p.divisi_id = d.id;
4

Menggunakan VIEW seperti tabel biasa

SELECT * FROM data_pegawai_lengkap WHERE nama_divisi = 'Keuangan' ORDER BY gaji DESC;
⚠️ View tidak menyimpan data secara fisik — setiap kali dipanggil, PostgreSQL akan menjalankan ulang query yang tersimpan di dalamnya berdasarkan data tabel terkini.
8 Latihan / Tugas Praktik

📝 Tugas Individu (khusus query SELECT)

  1. Tampilkan seluruh data pegawai diurutkan berdasarkan nama secara A–Z.
  2. Tampilkan pegawai dengan gaji antara Rp4.000.000 sampai Rp6.000.000 menggunakan BETWEEN.
  3. Cari pegawai yang namanya mengandung huruf "a" sebanyak lebih dari satu kali menggunakan wildcard LIKE.
  4. Tampilkan nama pegawai beserta nama divisinya menggunakan INNER JOIN, hanya untuk divisi "Keuangan" atau "Umum".
  5. Buat satu subquery untuk menampilkan pegawai dengan gaji tertinggi pada tabel pegawai.
  6. Ambil tangkapan layar setiap hasil query, lalu kumpulkan sesuai format yang ditentukan dosen.
9 Rangkuman & Kata Kunci

Pertemuan ini melatih mahasiswa menguasai berbagai variasi SELECT dan WHERE, mencari data dengan wildcard LIKE, serta menggabungkan data antar tabel menggunakan JOIN, subquery, dan view sebagai alat analisis data untuk pengambilan keputusan. Kemampuan ini menjadi bekal penting sebelum mahasiswa mengintegrasikan basis data Neon.Tech dengan Microsoft Access pada Pertemuan 9.
