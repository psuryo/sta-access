🟣 Pertemuan 9 · Integrasi Access & Neon.Tech

Koneksi Microsoft Access ke Remote Database

Menghubungkan Microsoft Access dengan basis data PostgreSQL di Neon.Tech melalui ODBC, sehingga data yang tersimpan di cloud dapat diakses dan dikelola langsung dari Access sebagai linked table.

📚 Kelompok: Integrasi & Aplikasi Access
🎯 Sub-CPMK: CPMK1 & CPMK2
🧭 Indikator: IK 1.2, IK 1.3
⏱️ Durasi: 100 menit
1 Tujuan Pembelajaran
  • Mahasiswa mampu menjelaskan konsep dan fungsi ODBC (Open Database Connectivity) dalam menghubungkan aplikasi lokal dengan basis data cloud.
  • Mahasiswa mampu memasang dan mengonfigurasi ODBC Driver PostgreSQL pada komputer.
  • Mahasiswa mampu menghubungkan Microsoft Access ke database Neon.Tech menggunakan fitur External Data.
  • Mahasiswa mampu menggunakan linked table pada Access untuk mendukung efisiensi kerja administrasi perkantoran secara digital.
2 Konsep Dasar Integrasi Access & Neon.Tech

Microsoft Access tidak dapat terhubung langsung ke PostgreSQL tanpa perantara. Diperlukan ODBC (Open Database Connectivity) — sebuah driver standar yang menjembatani aplikasi (Access) dengan berbagai jenis basis data (PostgreSQL di Neon.Tech). Setelah terhubung, tabel pada Neon.Tech dapat ditampilkan di Access sebagai linked table, yaitu tabel tertaut yang datanya tetap tersimpan di server Neon.Tech, namun dapat dilihat dan diolah seolah-olah merupakan tabel Access biasa.

🔌 ODBC

Standar konektivitas yang memungkinkan aplikasi seperti Access berkomunikasi dengan basis data non-Access, termasuk PostgreSQL.

🔗 Linked Table

Tabel di Access yang menampilkan data dari sumber eksternal secara real-time, tanpa menyalin/menduplikasi data.

🌐 DSN (Data Source Name)

Profil koneksi tersimpan yang berisi informasi server, database, dan kredensial untuk mempermudah koneksi berulang.

🔒 SSL Mode

Neon.Tech mewajibkan koneksi terenkripsi (SSL) demi keamanan data saat diakses dari luar.

3 Praktik: Memasang & Mengonfigurasi ODBC Driver PostgreSQL
1

Unduh driver ODBC PostgreSQL

Unduh psqlODBC (PostgreSQL ODBC Driver) sesuai versi Windows (32-bit/64-bit) dari situs resmi PostgreSQL, lalu jalankan installer hingga selesai.

2

Buka ODBC Data Source Administrator

Cari aplikasi ODBC Data Sources (64-bit) melalui menu pencarian Windows, lalu buka tab System DSN.

3

Tambahkan DSN baru

Klik Add, pilih driver PostgreSQL Unicode(x64), lalu isi form konfigurasi menggunakan data dari Neon Console:

Data Source : neon_administrasi Database : neondb Server : ep-xxxx.ap-southeast-1.aws.neon.tech Port : 5432 User Name : (sesuai akun Neon.Tech) SSL Mode : require
4

Uji koneksi

Klik tombol Test pada jendela konfigurasi. Notifikasi "Connection successful" menandakan ODBC sudah terhubung dengan benar ke Neon.Tech.

💡 Gunakan connection details yang sama seperti yang disalin pada Pertemuan 6 (host, database, username, password) agar konfigurasi ODBC sesuai dengan project Neon.Tech masing-masing.
4 Praktik: Menghubungkan Access ke Neon.Tech (Linked Table)
1

Buka menu External Data

Pada Microsoft Access, buka ribbon External Data, lalu pilih ODBC Database pada grup Import & Link.

2

Pilih metode "Link"

Pilih opsi Link to the data source by creating a linked table, lalu klik OK.

3

Pilih DSN yang sudah dibuat

Pada tab Machine Data Source, pilih DSN neon_administrasi yang telah dikonfigurasi sebelumnya, lalu masukkan username dan password Neon.Tech jika diminta.

4

Pilih tabel yang akan ditautkan

Centang tabel pegawai dan divisi dari daftar tabel Neon.Tech yang muncul, lalu klik OK.

5

Periksa hasil linked table

Tabel pegawai dan divisi akan muncul pada panel navigasi Access dengan ikon panah kecil (🔗), menandakan tabel tersebut tertaut ke sumber eksternal.

⚠️ Jangan menghapus atau mengganti nama linked table dari panel navigasi Access, karena tidak akan memengaruhi data asli di Neon.Tech — namun tautan koneksinya akan hilang dan harus dikonfigurasi ulang.
5 Praktik: Menggunakan Linked Table di Access
1

Membuka data melalui Datasheet View

Klik dua kali pada tabel pegawai di panel navigasi — data yang tampil merupakan data langsung dari Neon.Tech.

2

Membuat query sederhana di Access

Gunakan Query Design untuk menampilkan data linked table, misalnya menampilkan pegawai beserta divisinya menggunakan relasi Access seperti biasa.

3

Memverifikasi sinkronisasi data

Ubah salah satu data melalui SQL Editor Neon.Tech, lalu refresh linked table di Access (klik kanan → Refresh) untuk memastikan perubahan data langsung terlihat.

ℹ️ Linked table menjadi dasar penting bagi Pertemuan 10–13, di mana form dan report Access akan dibangun di atas data yang bersumber dari Neon.Tech ini.
6 Latihan / Tugas Praktik

📝 Tugas Individu

  1. Pasang ODBC Driver PostgreSQL dan buat DSN baru menggunakan connection details project Neon.Tech masing-masing.
  2. Hubungkan Microsoft Access ke Neon.Tech melalui menu External Data → ODBC Database, lalu tautkan tabel pegawai dan divisi.
  3. Buka linked table pegawai pada Access dan ambil tangkapan layar datanya.
  4. Ubah satu data pada SQL Editor Neon.Tech, lalu tunjukkan hasil refresh pada linked table di Access melalui tangkapan layar sebelum dan sesudah.
  5. Kumpulkan seluruh tangkapan layar beserta penjelasan singkat sesuai format yang ditentukan dosen.
7 Rangkuman & Kata Kunci

Pertemuan ini menjadi jembatan antara materi basis data lokal (Access) dan basis data cloud (Neon.Tech) yang telah dipelajari sebelumnya. Melalui ODBC dan linked table, data administrasi perkantoran dapat dikelola secara digital dan terpusat, mendukung efisiensi kerja sekaligus menjadi fondasi bagi pembuatan form dan report pada pertemuan berikutnya.
