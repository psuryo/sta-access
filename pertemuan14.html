Persiapan Ujian — Latihan UTS Basis Data

Latihan soal UTS berbentuk studi kasus Database Perpustakaan, mencakup seluruh materi Pertemuan 1–13: import data ke Neon.Tech, Primary/Foreign Key & Relationship, integrasi ODBC, query, form, dan report Microsoft Access.

📚 Mata Kuliah: Basis Data / Database
⏱️ Waktu: 120 menit
📝 Bentuk: Praktik Individu
🎯 Total Nilai: 100
🧭 CPMK: CPMK1 & CPMK2
📎 Berkas data anggota.csv, buku.csv, dan pinjam.csv (tersedia juga dalam format Excel) dapat diunduh melalui Edlink mata kuliah ini sebelum mulai mengerjakan latihan.

A Import Data ke Neon.Tech
20 poin · ±20 menit

Dosen menyediakan tiga file CSV (anggota.csv, buku.csv, pinjam.csv) yang berisi data perpustakaan untuk digunakan dalam latihan ini.

1. Membuat Database Neon.Tech 3 poin

Buat sebuah project/database PostgreSQL pada Neon.Tech dengan nama database/project:

uts_NIM

2. Import Data 5 poin

Import ketiga file CSV ke database Neon.Tech sehingga terbentuk tiga tabel: anggota, buku, pinjam. Pastikan seluruh data berhasil diimport sesuai jumlah berikut:

buku50
pinjam300

B Primary Key, Foreign Key & Relationship
20 poin · ±20 menit

Berdasarkan struktur dan isi data pada ketiga tabel, lakukan analisis untuk menentukan struktur database relasional yang tepat.

4. Menentukan Primary Key 7 poin

Tentukan Primary Key yang tepat untuk masing-masing tabel (anggota, buku, pinjam). Primary Key harus:

  • dapat mengidentifikasi record secara unik;
  • tidak boleh memiliki nilai duplikat;
  • tidak boleh bernilai NULL.

Terapkan Primary Key tersebut pada database PostgreSQL di Neon.Tech.

5. Menentukan Foreign Key 7 poin

Identifikasi field yang dapat digunakan sebagai Foreign Key berdasarkan hubungan antar data. Foreign Key harus memastikan bahwa:

  • setiap transaksi peminjaman mengacu pada anggota yang valid;
  • setiap transaksi peminjaman mengacu pada buku yang valid;
  • tidak terdapat referensi ke anggota atau buku yang tidak tersedia;
  • referential integrity tetap terjaga.
⚠️ Jangan membuat field baru. Gunakan field yang sudah tersedia pada tabel.

6. Membuat Relationship 6 poin

Berdasarkan Primary Key dan Foreign Key yang telah ditentukan:

  1. Tentukan tabel yang menjadi parent table.
  2. Tentukan tabel yang menjadi child table.
  3. Tentukan jenis relationship antar tabel.
  4. Tentukan field yang digunakan untuk menghubungkan tabel.
  5. Terapkan relationship tersebut pada database.
  6. Pastikan relationship menjaga referential integrity.
[TABEL A] │ │ 1 : N │ [TABEL B]
ℹ️ Field Primary Key, Foreign Key, dan hubungan antar tabel tidak diberikan dalam soal — analisis sendiri berdasarkan struktur dan makna data.
C Integrasi Neon.Tech dengan Microsoft Access
15 poin · ±15 menit

7. Konfigurasi ODBC 5 poin

Konfigurasikan koneksi ODBC agar Microsoft Access dapat terhubung dengan database PostgreSQL pada Neon.Tech, menggunakan informasi koneksi yang tersedia pada Neon Console. Pastikan koneksi dapat digunakan oleh Microsoft Access.

8. Membuat Linked Table 10 poin

Buat database Microsoft Access dengan nama:

UTS_NIM_Nama.accdb

Hubungkan tabel dari database Neon.Tech ke Microsoft Access menggunakan mekanisme Linked Table. Tabel yang harus tersedia di Access: anggota, buku, pinjam.

⚠️ Jangan membuat ulang ketiga tabel secara manual di Microsoft Access. Gunakan tabel yang terhubung dari database Neon.Tech.
D Query Microsoft Access
20 poin · ±25 menit

Gunakan tabel yang telah di-link dari Neon.Tech untuk seluruh query berikut.

9. Query Daftar Peminjaman 7 poin

Buat query dengan nama Q_DaftarPeminjaman yang menampilkan: Nomor Peminjaman, Tanggal Pinjam, Tanggal Kembali, Nama Anggota, Kota Anggota, Judul Buku, Pengarang, dan Status Buku — menggabungkan tabel pinjam, anggota, dan buku. Transaksi yang belum dikembalikan tetap ditampilkan dengan tanggalkembali berupa NULL.

10. Query Status Peminjaman 7 poin

Buat query dengan nama Q_StatusPeminjaman yang menampilkan: Nomor Peminjaman, Nama Anggota, Judul Buku, Tanggal Pinjam, Tanggal Kembali, dan Status Peminjaman. Buat Calculated Field bernama StatusPeminjaman:

  • Jika tanggalkembali bernilai NULL → tampilkan Belum Dikembalikan.
  • Jika tanggalkembali memiliki nilai → tampilkan Sudah Dikembalikan.

11. Query Rekap Peminjaman Buku 6 poin

Buat query dengan nama Q_RekapPeminjamanBuku yang menampilkan: Nomor Buku, Judul Buku, Pengarang, dan Total Peminjaman menggunakan fungsi agregat COUNT(), dikelompokkan berdasarkan buku, dan diurutkan berdasarkan Total Peminjaman dari terbesar ke terkecil.

E Form Microsoft Access
10 poin · ±15 menit

Buat form dengan nama F_Peminjaman untuk menampilkan dan/atau menginput data transaksi peminjaman. Form minimal menampilkan: Nomor Peminjaman, Tanggal Pinjam, Tanggal Kembali, Nomor Buku, Judul Buku, Nomor Anggota, Nama Anggota, dan Status Peminjaman. Jika memungkinkan, gunakan Combo Box untuk pemilihan Buku dan Anggota. Form harus menggunakan data dari Neon.Tech melalui Linked Table.

F Report Microsoft Access
15 poin · ±20 menit

Buat report dengan nama R_LaporanPeminjaman menggunakan Q_DaftarPeminjaman sebagai sumber data, dengan judul "LAPORAN PEMINJAMAN BUKU". Report minimal menampilkan: Nomor Peminjaman, Tanggal Pinjam, Tanggal Kembali, Nama Anggota, Kota, Judul Buku, Pengarang, dan Status Peminjaman.

  • Grouping: dikelompokkan berdasarkan Kota Anggota.
  • Footer: tambahkan Total Transaksi Peminjaman menggunakan fungsi agregat yang sesuai.

📤 Pengumpulan

Pada akhir latihan/ujian, kumpulkan 2 item berikut.

1. Link Database Neon.Tech

Kumpulkan link database Neon.Tech yang dapat digunakan dosen untuk pemeriksaan, lengkap dengan informasi akses (password/database credential) sesuai instruksi dosen.

Pastikan database masih aktif dan dapat diakses saat proses pemeriksaan.

2. Database Microsoft Access

Kumpulkan database UTS_NIM_Nama.accdb dalam bentuk ZIP:

UTS_NIM_Nama.zip
💡 Gunakan credential khusus untuk keperluan UTS, bukan password akun pribadi yang digunakan untuk layanan lain.
📋 Ketentuan Ujian
  1. UTS/latihan dikerjakan secara individu.
  2. Gunakan akun Neon.Tech masing-masing.
  3. Gunakan file data yang diberikan dosen (diunduh dari Edlink).
  4. Jangan mengubah isi data sumber kecuali diperlukan untuk memperbaiki tipe/struktur database.
  5. Jangan membuat ulang tabel secara manual di Microsoft Access.
  6. Microsoft Access harus menggunakan Linked Table dari database Neon.Tech.
  7. Primary Key dan Foreign Key harus ditentukan berdasarkan analisis mahasiswa sendiri.
  8. Relationship harus dibuat berdasarkan struktur dan makna data.
  9. Pastikan database Neon.Tech dapat diakses oleh dosen pada saat pemeriksaan.
  10. Pastikan file Microsoft Access dapat dibuka setelah diekstrak dari ZIP.
  11. Nama file harus mengikuti format: UTS_NIM_Nama.zip.
  12. Gunakan waktu pengerjaan secara efektif.
