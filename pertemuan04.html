Query Dasar (SELECT, WHERE, ORDER BY)

Membuat query select untuk menampilkan data, memfilter data dengan kriteria WHERE, mengurutkan hasil dengan ORDER BY, dan bekerja dengan Query Design View.

⏱️ 90 menit 🎯 Praktik Inti 📦 Microsoft Access

Tujuan Pembelajaran

  • Memahami konsep dan fungsi query dalam pengolahan data.
  • Mampu membuat Select Query melalui Query Design View maupun SQL View.
  • Mampu memfilter data menggunakan berbagai kriteria (Criteria/WHERE).
  • Mampu mengurutkan hasil query dengan Sort (ORDER BY).
  • Mengenal dasar-dasar sintaks SQL yang dihasilkan oleh query Access.

1. Apa itu Query?

Query adalah objek Access yang digunakan untuk menampilkan, menyaring, atau mengolah data dari satu tabel atau lebih sesuai kebutuhan. Berbeda dengan tabel yang menyimpan data mentah, query menampilkan data secara dinamis berdasarkan kriteria yang ditentukan, tanpa mengubah data aslinya.

Jenis query yang paling umum digunakan adalah Select Query, yaitu query yang digunakan untuk menampilkan data dari tabel berdasarkan field dan kondisi tertentu.

2. Membuat Select Query melalui Design View

  1. Buka tab Create, lalu klik Query Design.
  2. Pada jendela Show Table, pilih tabel yang akan digunakan, misalnya Buku, klik Add, lalu Close.
  3. Klik dua kali pada field yang ingin ditampilkan (misalnya JudulBuku, Pengarang, Stok) sehingga masuk ke grid query di bagian bawah.
  4. Klik tombol Run (ikon tanda seru merah) pada Ribbon untuk menjalankan query.
  5. Simpan query dengan menekan Ctrl+S, beri nama misalnya qryDaftarBuku.
Perlu diketahui: Hasil query dapat ditampilkan dalam Datasheet View seperti tabel biasa, namun datanya selalu mengikuti kondisi terbaru dari tabel sumber setiap kali query dijalankan.

3. Memfilter Data dengan Criteria (WHERE)

Baris Criteria pada grid Query Design digunakan untuk menyaring data yang ditampilkan, setara dengan klausa WHERE pada SQL.

Contoh Kriteria Penjelasan
"Fiksi" Menampilkan data dengan nilai teks persis sama dengan "Fiksi"
>10 Menampilkan data numerik yang nilainya lebih besar dari 10
Between 1 And 5 Menampilkan data dengan nilai di antara 1 sampai 5
Like "A*" Menampilkan data teks yang diawali huruf A
Is Null Menampilkan data yang field-nya masih kosong
>=#01/01/2026# Menampilkan data tanggal mulai 1 Januari 2026
Tips: Kriteria yang ditulis pada baris yang sama akan digabung dengan logika AND, sedangkan kriteria yang ditulis pada baris Or di bawahnya akan digabung dengan logika OR.

4. Mengurutkan Data dengan Sort (ORDER BY)

Baris Sort pada grid Query Design digunakan untuk mengatur urutan tampilan data, setara dengan klausa ORDER BY pada SQL.

  1. Klik pada baris Sort di bawah kolom field yang ingin diurutkan.
  2. Pilih Ascending untuk urutan dari kecil ke besar (A-Z), atau Descending untuk urutan sebaliknya (Z-A).
  3. Jika lebih dari satu kolom diberi Sort, urutan pengurutan mengikuti posisi kolom dari kiri ke kanan.

5. Melihat Sintaks SQL

Setiap query yang dibuat lewat Design View sebenarnya diterjemahkan Access menjadi perintah SQL di belakang layar. Untuk melihatnya, klik kanan pada tab query lalu pilih SQL View.

SELECT JudulBuku, Pengarang, Stok FROM Buku WHERE Stok > 0 ORDER BY JudulBuku ASC;

Struktur dasar tersebut terdiri dari SELECT (field yang ditampilkan), FROM (tabel sumber), WHERE (kriteria filter), dan ORDER BY (urutan hasil).

6. Langkah Praktik

  1. Buka kembali database PerpustakaanKu.accdb.
  2. Buat query qryBukuTersedia yang menampilkan JudulBuku, Pengarang, dan Stok dari tabel Buku, dengan kriteria Stok lebih besar dari 0.
  3. Urutkan hasil query tersebut berdasarkan JudulBuku secara Ascending.
  4. Buat query kedua bernama qryAnggotaBaru yang menampilkan Nama dan TanggalDaftar dari tabel Anggota, dengan kriteria TanggalDaftar pada tahun 2026.
  5. Buka SQL View pada kedua query tersebut dan amati sintaks SQL yang terbentuk.

Ringkasan

  • Query digunakan untuk menampilkan dan menyaring data tanpa mengubah data pada tabel sumber.
  • Select Query dapat dibuat melalui Query Design View dengan memilih tabel dan field yang dibutuhkan.
  • Baris Criteria berfungsi sebagai filter data, setara dengan klausa WHERE pada SQL.
  • Baris Sort berfungsi mengurutkan hasil query, setara dengan klausa ORDER BY pada SQL.
  • Setiap query yang dibuat lewat Design View dapat dilihat sintaks SQL-nya melalui SQL View.

Latihan Mandiri

  1. Jelaskan perbedaan fungsi antara baris Criteria dan baris Sort pada Query Design View.
  2. Tuliskan kriteria yang tepat untuk menampilkan buku dengan judul yang mengandung kata "Data".
  3. Buat query yang menampilkan anggota yang mendaftar antara 1 Januari 2026 sampai 30 Juni 2026, diurutkan berdasarkan TanggalDaftar secara Descending.
