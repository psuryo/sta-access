Query dalam Remote Database — DDL & DML

Mempraktikkan perintah dasar SQL pada PostgreSQL di Neon.Tech: membuat struktur tabel (DDL) dengan CREATE TABLE, serta mengelola isi data (DML) dengan INSERT, UPDATE, dan DELETE melalui SQL Editor.

📚 Kelompok: Remote Database — Neon.Tech
🎯 Sub-CPMK: CPMK2
🧭 Indikator: IK 1.3, IK 3.1
⏱️ Durasi: 100 menit
1 Tujuan Pembelajaran
  • Mahasiswa mampu membedakan perintah DDL (Data Definition Language) dan DML (Data Manipulation Language).
  • Mahasiswa mampu membuat tabel baru pada database Neon.Tech menggunakan perintah CREATE TABLE.
  • Mahasiswa mampu menambah, mengubah, dan menghapus data menggunakan perintah INSERT, UPDATE, dan DELETE.
  • Mahasiswa mampu menjalankan dan memeriksa hasil query pada SQL Editor Neon.Tech sebagai alat analisis data administrasi perkantoran.
2 Konsep Dasar DDL & DML

Dalam bahasa SQL, perintah dikelompokkan berdasarkan fungsinya. Dua kelompok yang dipelajari pada pertemuan ini adalah DDL untuk mendefinisikan struktur basis data, dan DML untuk mengelola isi (data) di dalam struktur tersebut.

🏗️ DDL — Data Definition Language

Digunakan untuk membuat, mengubah, atau menghapus struktur objek basis data (tabel, kolom, tipe data).

  • CREATE TABLE — membuat tabel baru
  • ALTER TABLE — mengubah struktur tabel
  • DROP TABLE — menghapus tabel

✏️ DML — Data Manipulation Language

Digunakan untuk mengelola isi data di dalam tabel yang sudah ada.

  • INSERT — menambah data baru
  • UPDATE — mengubah data yang ada
  • DELETE — menghapus data
3 Praktik: Membuat Tabel dengan CREATE TABLE
1

Buka SQL Editor

Masuk ke project Neon.Tech yang sudah dibuat pada Pertemuan 6, lalu klik menu SQL Editor pada panel kiri Neon Console.

2

Tulis perintah CREATE TABLE

Buat tabel pegawai untuk menyimpan data administrasi perkantoran sederhana:

CREATE TABLE pegawai ( id SERIAL PRIMARY KEY, nama VARCHAR(100) NOT NULL, jabatan VARCHAR(50), tanggal_masuk DATE, gaji NUMERIC(12,2) );
3

Jalankan query

Klik tombol Run (atau tekan Ctrl+Enter) untuk mengeksekusi perintah. Notifikasi "Success" menandakan tabel berhasil dibuat.

4

Periksa tabel yang terbentuk

Buka menu Tables pada Neon Console untuk memastikan tabel pegawai beserta kolom-kolomnya sudah tersimpan.

💡 Kolom bertipe SERIAL akan otomatis membuat nilai id yang unik dan bertambah (auto-increment) setiap kali data baru ditambahkan.
4 Praktik: Mengelola Data dengan INSERT, UPDATE, DELETE
1

Menambah data — INSERT

Tambahkan beberapa data pegawai ke dalam tabel:

INSERT INTO pegawai (nama, jabatan, tanggal_masuk, gaji) VALUES ('Siti Aminah', 'Staf Administrasi', '2022-03-01', 4500000), ('Budi Santoso', 'Sekretaris', '2021-07-15', 5200000);
2

Menampilkan data — SELECT

Periksa data yang sudah masuk dengan perintah dasar:

SELECT * FROM pegawai;
3

Mengubah data — UPDATE

Perbarui gaji pegawai tertentu, misalnya kenaikan gaji untuk Budi Santoso:

UPDATE pegawai SET gaji = 5700000 WHERE nama = 'Budi Santoso';
4

Menghapus data — DELETE

Hapus satu baris data pegawai yang sudah tidak aktif:

DELETE FROM pegawai WHERE nama = 'Siti Aminah';
⚠️ Selalu sertakan klausa WHERE pada UPDATE dan DELETE. Tanpa WHERE, perintah akan mengubah atau menghapus seluruh baris pada tabel.
5 Latihan / Tugas Praktik

📝 Tugas Individu

  1. Buat tabel baru bernama surat_masuk dengan kolom: id, nomor_surat, pengirim, tanggal_terima, dan perihal.
  2. Tambahkan minimal 5 data surat masuk menggunakan perintah INSERT.
  3. Ubah data salah satu surat menggunakan perintah UPDATE (misalnya memperbaiki perihal surat).
  4. Hapus satu data surat menggunakan perintah DELETE beserta klausa WHERE yang tepat.
  5. Ambil tangkapan layar hasil setiap query beserta pesan sukses dari SQL Editor, lalu kumpulkan sesuai format yang ditentukan dosen.
6 Rangkuman & Kata Kunci

Kemampuan ini menjadi bekal untuk pertemuan berikutnya, yaitu query lanjutan menggunakan JOIN dan subquery untuk menganalisis data dari beberapa tabel sekaligus.
