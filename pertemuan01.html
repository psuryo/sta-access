Pengenalan Database & Microsoft Access

Memahami konsep dasar database relasional serta mengenal antarmuka dan objek-objek utama dalam Microsoft Access.

⏱️ 90 menit 🎯 Teori & Praktik Dasar 📦 Microsoft Access

Tujuan Pembelajaran

  • Memahami apa itu database dan mengapa data perlu dikelola secara terstruktur.
  • Mengenal konsep database relasional (tabel, baris, kolom, relasi).
  • Mengenal Microsoft Access sebagai aplikasi RDBMS berbasis desktop.
  • Memahami fungsi setiap objek utama dalam Access: Table, Query, Form, Report, Macro, dan Module.
  • Mampu membuka, menavigasi, dan mengenali komponen antarmuka Access (Ribbon, Navigation Pane, Backstage View).

1. Apa itu Database?

Database (basis data) adalah kumpulan data yang terorganisir sedemikian rupa sehingga dapat diakses, dikelola, dan diperbarui dengan mudah. Data disimpan secara terstruktur agar tidak terjadi duplikasi yang tidak perlu dan mudah dicari kembali (retrieval).

Beberapa alasan mengapa data perlu disimpan dalam database dibandingkan hanya menggunakan spreadsheet biasa:

  • Konsistensi data — menghindari data ganda atau bertentangan.
  • Integritas data — aturan validasi memastikan data yang masuk sesuai format.
  • Keamanan — akses data dapat dibatasi berdasarkan pengguna.
  • Skalabilitas — mampu menangani data dalam jumlah besar secara efisien.
  • Relasi antar data — memungkinkan data yang saling berhubungan dikelola bersama.

Database Relasional (RDBMS)

RDBMS (Relational Database Management System) adalah sistem manajemen basis data yang menyimpan data dalam bentuk tabel-tabel yang saling berhubungan (berelasi) melalui kunci (key). Contoh RDBMS: Microsoft Access, MySQL, PostgreSQL, SQL Server, Oracle.

Istilah Penjelasan
Table (Tabel) Kumpulan data sejenis yang tersusun dalam baris dan kolom
Field (Kolom) Atribut/kategori data, misalnya Nama, Alamat, Tanggal Lahir
Record (Baris) Satu kesatuan data lengkap dalam tabel, misalnya data satu siswa
Primary Key Kolom unik yang menjadi identitas setiap record (tidak boleh sama/kosong)
Relationship Hubungan antar tabel melalui key yang saling terkait

2. Mengenal Microsoft Access

Microsoft Access adalah aplikasi RDBMS berbasis desktop dari Microsoft Office yang memungkinkan pengguna membuat, mengelola, dan mengolah database tanpa perlu menulis banyak kode. Access menyediakan antarmuka visual (GUI) untuk membuat tabel, query, form, dan report secara drag-and-drop.

Kapan menggunakan Access? Cocok untuk aplikasi database skala kecil–menengah seperti pencatatan inventori, data siswa, data pelanggan, atau prototipe sebelum migrasi ke database server seperti SQL Server atau PostgreSQL.

Komponen Antarmuka Access

  • Backstage View — tampilan awal untuk membuat database baru atau membuka database yang sudah ada.
  • Ribbon — kumpulan tab (Home, Create, External Data, Database Tools) berisi tombol perintah.
  • Navigation Pane — panel di sisi kiri yang menampilkan seluruh objek database (tabel, query, form, report).
  • Object Tabs — area kerja utama tempat tabel/form/report yang sedang dibuka ditampilkan.
  • Status Bar — informasi status di bagian bawah jendela, termasuk tombol ganti tampilan (View).

3. Objek Utama dalam Microsoft Access

Sebuah database Access terdiri dari beberapa jenis objek yang saling terintegrasi:

🗄️

Table

Menyimpan data mentah dalam struktur baris dan kolom. Objek paling dasar dalam database.

🔍

Query

Digunakan untuk mengambil, menyaring, dan mengolah data dari satu atau beberapa tabel.

🧾

Form

Antarmuka untuk memasukkan dan mengedit data dengan tampilan yang lebih ramah pengguna.

📊

Report

Menyajikan data dalam format cetak/tampilan ringkas untuk keperluan laporan.

⚙️

Macro

Kumpulan perintah otomatis tanpa kode, untuk menjalankan aksi tertentu secara otomatis.

💻

Module

Kumpulan kode VBA (Visual Basic for Applications) untuk logika program yang lebih kompleks.

4. Langkah Praktik: Menjelajahi Antarmuka Access

  1. Buka aplikasi Microsoft Access dari Start Menu.
  2. Pada Backstage View, perhatikan pilihan "Blank Database" dan template yang tersedia.
  3. Klik Blank Database, beri nama LatihanSesi1.accdb, lalu klik Create.
  4. Perhatikan Navigation Pane di sisi kiri — akan muncul Table1 secara otomatis.
  5. Jelajahi tab-tab pada Ribbon: Home, Create, External Data, Database Tools.
  6. Coba ganti tampilan tabel dari Datasheet View ke Design View menggunakan tombol View di pojok kiri bawah.
  7. Simpan database, lalu tutup Access.
Tips: Biasakan menyimpan database dengan nama yang deskriptif dan simpan di folder khusus per pertemuan agar mudah dicari kembali saat latihan atau ujian.

Ringkasan

  • Database menyimpan data secara terstruktur agar konsisten, aman, dan mudah dikelola.
  • RDBMS mengorganisir data dalam tabel-tabel yang saling berelasi melalui key.
  • Microsoft Access adalah RDBMS desktop dengan antarmuka visual, cocok untuk skala kecil–menengah.
  • Objek utama Access: Table, Query, Form, Report, Macro, dan Module.
  • Navigation Pane dan Ribbon adalah dua komponen antarmuka yang paling sering digunakan.

Latihan Mandiri

  1. Sebutkan 3 contoh RDBMS selain Microsoft Access.
  2. Jelaskan perbedaan antara Field dan Record dalam sebuah tabel.
  3. Buat database baru bernama PerpustakaanKu.accdb dan jelajahi seluruh tab pada Ribbon.
