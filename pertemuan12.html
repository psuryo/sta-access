Report dalam Access

Merancang laporan (report) menggunakan Report Wizard dan Design View, mengelompokkan serta mengurutkan data, menyusun header/footer, dan menampilkan hasil laporan melalui Print Preview sebagai dokumen administrasi perkantoran yang siap dicetak.

📚 Kelompok: Integrasi & Aplikasi Access
🎯 Sub-CPMK: CPMK1
🧭 Indikator: IK 1.2, IK 1.3
⏱️ Durasi: 100 menit
1 Tujuan Pembelajaran
  • Mahasiswa mampu menjelaskan fungsi report sebagai media penyajian dan pencetakan data pada Microsoft Access.
  • Mahasiswa mampu membuat report menggunakan Report Wizard dan menyesuaikannya melalui Design View.
  • Mahasiswa mampu mengelompokkan (grouping) dan mengurutkan (sorting) data pada report.
  • Mahasiswa mampu mengatur header/footer serta menampilkan hasil laporan melalui Print Preview untuk mendukung efisiensi kerja administrasi perkantoran secara digital.
2 Konsep Dasar Report Access

Report adalah objek Access yang dirancang khusus untuk menyajikan data dalam format yang rapi dan siap cetak, berbeda dengan form yang difokuskan untuk input data. Report umumnya digunakan untuk membuat rekap, daftar, atau laporan resmi seperti daftar pegawai per divisi.

Setiap report tersusun atas beberapa bagian (band/section) yang menentukan di mana suatu elemen akan dicetak pada laporan:

🧙 Report Wizard

Fitur otomatis untuk membuat report secara cepat berdasarkan tabel/query, lengkap dengan pilihan grouping dan sorting.

🎨 Design View

Mode perancangan manual untuk mengatur tata letak, band, dan kontrol pada report secara rinci.

🗂️ Grouping

Mengelompokkan data berdasarkan kolom tertentu (misalnya divisi), lengkap dengan header/footer per kelompok.

🖨️ Print Preview

Tampilan pratinjau laporan sebelum dicetak, menunjukkan hasil akhir persis seperti saat dicetak di kertas.

3 Praktik: Membuat Report dengan Report Wizard
1

Pilih sumber data

Pada panel navigasi, pilih tabel/linked table pegawai, atau gunakan query hasil JOIN dengan tabel divisi dari Pertemuan 8 agar nama divisi ikut tampil.

2

Jalankan Report Wizard

Buka ribbon Create → grup Reports → klik Report Wizard.

3

Pilih field yang ditampilkan

Pindahkan field nama, jabatan, nama_divisi, dan gaji ke kolom Selected Fields, lalu klik Next.

4

Tentukan tingkat pengelompokan

Pilih nama_divisi sebagai level grouping, sehingga data pegawai akan dikelompokkan berdasarkan divisinya masing-masing.

5

Tentukan urutan data — Sorting

Atur pengurutan data di dalam tiap kelompok, misalnya berdasarkan nama secara A–Z, lalu klik Next hingga Finish.

💡 Grouping paling efektif digunakan pada kolom yang memiliki beberapa kategori berulang, seperti divisi, jabatan, atau tanggal — bukan pada kolom yang nilainya unik seperti nama pegawai.
4 Praktik: Mengatur Grouping & Sorting di Design View
1

Buka panel Group, Sort, and Total

Pada Design View report, buka ribbon Design → Grouping & Totals → Group & Sort untuk menampilkan panel pengaturan di bagian bawah layar.

2

Tambahkan Total pada Group Footer

Pada baris grouping nama_divisi, klik More → lalu aktifkan with Sum pada kolom gaji agar subtotal gaji per divisi otomatis muncul di Group Footer.

3

Tambahkan level sorting kedua

Klik Add a sort, lalu pilih kolom gaji dengan urutan from largest to smallest agar pegawai dengan gaji tertinggi tampil lebih dulu dalam tiap divisi.

5 Praktik: Mengatur Header, Footer & Print Preview
1

Menyesuaikan Report Header

Tambahkan label judul laporan pada bagian Report Header, misalnya "Laporan Data Pegawai per Divisi", lengkap dengan logo atau nama instansi jika diperlukan.

2

Menambahkan nomor halaman pada Page Footer

Gunakan ribbon Design → Header/Footer → Page Numbers, lalu pilih format "Page N of M" agar nomor halaman tampil otomatis di setiap halaman.

3

Menambahkan tanggal cetak

Gunakan ribbon Design → Header/Footer → Date and Time untuk menampilkan tanggal saat laporan dicetak pada Page Footer.

4

Melihat hasil melalui Print Preview

Klik kanan pada report, pilih Print Preview untuk memeriksa tata letak, grouping, subtotal, serta header/footer sebelum laporan benar-benar dicetak atau diekspor ke PDF.

ℹ️ Pada Print Preview, gunakan ribbon Print Preview → Export → PDF or XPS untuk menyimpan laporan sebagai berkas PDF yang siap dibagikan.
6 Latihan / Tugas Praktik

📝 Tugas Individu

  1. Buat report data pegawai menggunakan Report Wizard, dikelompokkan berdasarkan nama_divisi.
  2. Tambahkan subtotal gaji (Sum) pada Group Footer setiap divisi.
  3. Atur sorting data di dalam kelompok berdasarkan gaji dari yang tertinggi ke terendah.
  4. Tambahkan judul laporan pada Report Header, serta nomor halaman dan tanggal cetak pada Page Footer.
  5. Tampilkan hasil akhir melalui Print Preview, lalu ekspor sebagai PDF dan kumpulkan sesuai format yang ditentukan dosen.
7 Rangkuman & Kata Kunci

Pertemuan ini membekali mahasiswa dengan kemampuan menyusun laporan data yang rapi dan informatif menggunakan Report Wizard dan Design View, lengkap dengan grouping, sorting, header/footer, hingga siap dicetak melalui Print Preview. Kemampuan ini penting untuk menghasilkan dokumen administrasi perkantoran yang profesional, serta menjadi dasar sebelum mempelajari fitur report lanjutan pada Pertemuan 13.
